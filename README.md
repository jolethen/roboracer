## Pin Mapping (TB6612FNG Driver)
- **PWMA (Left Motor Speed):** GPIO 25
- **AIN1 (Left Motor Dir 1):** GPIO 26
- **AIN2 (Left Motor Dir 2):** GPIO 27
- **PWMB (Right Motor Speed):** GPIO 18
- **BIN1 (Right Motor Dir 1):** GPIO 32
- **BIN2 (Right Motor Dir 2):** GPIO 33
- **STBY (Driver Standby):** GPIO 19
